README – Bright Future Technologies Application
Bright Future Technologies Application
About

This is a Java console application used to manage products for Bright Future Technologies.

Features
Capture new products
Search for products
Update product details
Delete products
Print a product report
Exit the application

The program stores up to 10 products using an array. Each product contains a code, name, category, warranty, price, stock level, and supplier.

Classes
JavaApplication3 – Starts the program and handles the main menu.
Products – Handles all product operations.
ReportData – Stores and manages individual product information.
Technologies

The project uses Java, Scanner, arrays, loops, methods, classes, objects, and encapsulation.

Limitations

Product information is only stored while the program is running, and the system can hold a maximum of 10 products.

Overall, the application provides a simple way to manage and report on product information.
